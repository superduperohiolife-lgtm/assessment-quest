# Business Quest（社内アセスメント試験アプリ）

会計・財務・経営戦略・マーケティング、およびクリティカル・シンキング（CT）の社内アセスメント用 問題演習アプリ。
レトロRPG風のUIで、回答ごとに ◯✕ と解説を表示し、終了時に正答率・ランク・分野別結果を表示する。

- 公開URL：https://superduperohiolife-lgtm.github.io/assessment-quest/
- 対象環境：PCブラウザ（スマホ幅でも表示可）

## 構成

| 層 | 技術 | 役割 |
|---|---|---|
| フロント | GitHub Pages（本リポジトリ：`index.html` / `app.js`） | 画面・出題・採点表示のみ。**問題データは含まない** |
| バックエンド | Google Apps Script（Web App） | 職番認証、問題配信、受験ログ保存、本人履歴、管理者API |
| データ | Google スプレッドシート／Drive | 職番マスタ・ログイン履歴・受験結果・回答明細／問題バンク（JSON） |

- 問題・正解・解説は Drive 上の非公開 JSON に保持し、**登録職番でログインしたときだけ**配信する
- 受験結果は職番ごとに保存し、**本人の記録のみ**を返す（他の職番の結果は表示されない）
- 管理者用のパスワード等の秘匿値は GAS の Script Properties に保持（本リポジトリには置かない）

## 使い方

1. 事前登録された **8桁の職番（英数字。例：先頭英字＋数字7桁）** でログイン
2. 「ビジネス基礎の大陸」（4分野＋ミックス）または「試練の塔（CT）」を選択
3. クエスト（10問）／ロングクエスト（20問）／リベンジ（過去の誤答から）を選択
4. 回答ごとに解説を確認し、最後に結果とふりかえりを確認

キー操作：`1`〜`4`（または `A`〜`D`）で回答、`Enter` で次へ。

## 運用

- 受験者の追加・無効化：スプレッドシート「AssessmentQuest_DB」の「職番マスタ」シートを編集（有効列を `FALSE` にすると無効）
- 問題の追加・修正：Drive の `assessment_bank.json` を差し替え
- API の URL：`index.html` の `API_URL` に GAS Web App の URL を設定

## デプロイ

`main` への push で GitHub Actions（`.github/workflows/pages.yml`）が Pages に自動デプロイする。
